## 🏗️ Backend Architecture I'm Working With

I follow a **Layered Modular Architecture** for backend development:

```text
src/
└── modules/
    └── feature/
        ├── controllers/
        ├── services/
        ├── repositories/
        ├── schemas/
        ├── dtos/
        ├── entities/
        ├── routes/
        └── index.ts
```

This helps keep applications:

* ✅ Modular
* ✅ Maintainable
* ✅ Testable
* ✅ Scalable
* ✅ Easy to understand
